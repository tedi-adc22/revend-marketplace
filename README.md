T# Revend Marketplace

A modern, full-stack marketplace web application built with Next.js (App Router), React, and Supabase. **Revend** allows users to browse item listings, view detailed product pages, post new items, and handle secure user authentication.

> 🚧 **Work in Progress:** This project is actively under development. New features, UI refinements, and optimization updates are being pushed regularly.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, JavaScript/JSX)
- **Frontend UI:** [React](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/)
- **Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL, Row Level Security, Storage)
- **Authentication:** Supabase Auth (PKCE flow, Email/Password, Password Resets)
- **Deployment:** [Vercel](https://vercel.com/)

---

## ✨ Features & Architecture

- **Dynamic Item Listings:** Browse items with optimized image loading using `next/image`.
- **Detailed Item Pages:** Full image galleries, pricing, item condition badges, and seller details.
- **Authentication Flow:** Secure login, sign-up, email callback routing, and password reset workflows.
- **View Tracking & Analytics:** Real-time tracking of item listing views.
- **Responsive Layout:** Tailored design for mobile, tablet, and desktop viewports using Tailwind CSS.
